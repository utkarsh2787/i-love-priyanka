# Birthday diary

Static site: just `index.html`, `style.css`, `app.js` and `assets/`.

- Unlocks at 8 Oct 2026 00:00 IST. Test: `?in=15` (unlock in 15s), `?open`, `?skip&p=5`.
- Edit name / sign-off / timing at the top of `app.js`.
- Song: put a file at `assets/song.mp3` (otherwise a built-in music-box Happy Birthday plays).
- Deploy: drag this folder onto https://app.netlify.com/drop or run `npx vercel --prod`.

Song: `assets/song.mp3` is "Happy Birthday to You" (public domain, Wikimedia Commons, by Pracchia-78). Replace it with any mp3 you like.
